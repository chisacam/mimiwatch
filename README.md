# mimiwatch

YouTube 영상과 라이브 방송을 **자신의 언어로 이해하기 위한 로컬 도구**입니다. 원본 영상 위에 전사 자막과 번역 자막을 얹어 보여 줍니다.

[hayamimi](https://github.com/oboroge0/hayamimi)를 전사 엔진으로 사용하는 별도 프로젝트이며, hayamimi 저장소를 수정하지 않고 라이브러리로만 연결합니다.

## 무엇을 하는가

**녹화본**: 주소를 넣으면 오디오를 받아 전사하고 번역합니다. 각 발화에 미디어 타임스탬프가 붙으므로 YouTube 플레이어의 재생 위치와 **자동으로 정렬**됩니다. 오프셋 조정이 필요 없습니다.

**라이브**: 진행 중인 방송을 실시간으로 전사하고 번역합니다. 확정 자막이 먼저 나가고, 2패스 정제본이 도착하면 조용히 교체합니다.

**언어가 같으면 아무것도 하지 않습니다.** 한국어 사용자가 한국어 영상을 볼 때는 번역도 자막도 켜지 않습니다. 오른쪽 스크립트 패널이 이미 텍스트를 담고 있기 때문입니다.

## 요구 사항

- Python 3.10 이상
- [hayamimi](https://github.com/oboroge0/hayamimi)를 내려받고 모델을 설치해 둔 상태
- `yt-dlp`, `ffmpeg`

```bash
brew install yt-dlp ffmpeg
```

## 실행

```bash
export HAYAMIMI_DIR=/path/to/hayamimi     # 기본값: /Users/chiyak/hobby/hayamimi
./run.sh                                   # http://localhost:8900
```

hayamimi의 가상환경을 그대로 씁니다. 별도 의존성 설치가 필요 없습니다.

## 엔진 교체

전사와 번역 모두 로컬이 기본이며, 상단 ⚙ 버튼에서 외부 엔진을 등록할 수 있습니다.

| | 기본 | 외부 |
|---|---|---|
| 전사 | hayamimi (언어별 전문 모델) | OpenAI 호환 `/v1/audio/transcriptions` · **녹화본 한정** |
| 번역 | M2M-100 418M | OpenAI 호환 `/v1/chat/completions` |

외부 번역 엔드포인트가 응답하지 않으면 로컬로 대체하며, 화면에 어느 엔진이 몇 건을 처리했는지 표시합니다.

`backends.json`은 저장소에 포함되지 않습니다. 첫 실행 시 `backends.example.json`에서 복사되며, API 키는 그 파일에 직접 넣으십시오.

## 실측 결과 요약

2026-08-27, 맥북(CPU 전용) 기준입니다. 자세한 내용은 `measurements/RESULTS.md`에 있습니다.

| 항목 | 결과 |
|---|---|
| 녹화본 전사 속도 | 실시간의 38~88배 (30분 영상 20초) |
| 번역 속도 | 로컬 M2M-100 0.2초/줄, Gemma 4 E4B 0.26초/줄 |
| 라이브 지연 | 발화 종료 후 확정 자막 약 0.05초, 번역 약 0.7초 |
| 라이브 추종 | 방송 끝에서 약 3초 뒤 |

## 알려진 한계

- **겹친 발화는 분리되지 않습니다.** 화자 태그(CAM++)는 화자가 바뀐 것을 알려 줄 뿐이며, 여러 사람이 동시에 말하면 한 명만 받아 적습니다.
- **라이브는 외부 전사 엔진을 쓸 수 없습니다.** 실시간 세그먼트 처리 구조상 아직 연결하지 않았습니다.
- **작업 상태가 영속되지 않습니다.** 서버를 재시작하면 진행 중인 라이브 세션이 사라집니다.
- **yt-dlp 경로는 깨질 수 있습니다.** YouTube 변경에 취약하므로 m3u8 직접 입력을 1급 입력으로 두었습니다.
