# Resolves the audio stream out of a video URL. `[default]` brings in yt-dlp-ejs
# (the script that solves YouTube's JS challenge) -- since 2025.11 YouTube needs
# an external JS runtime (deno), and without the script the formats disappear on
# the VOD and cookie (members-only) paths. The runtime comes from Models & Tools
# (deno, in modelhub).
#
# There is a reason this is here rather than whatever the system has. YouTube
# changes its extraction path often and yt-dlp follows each time, but a copy
# installed by winget or brew does not update itself. After a few months it
# fails to read the format list at all and live becomes "yt-dlp could not find
# any audio at this URL." (issue #1). Kept in the virtualenv, running the
# install script again is the update.
yt-dlp[default]>=2025.1
